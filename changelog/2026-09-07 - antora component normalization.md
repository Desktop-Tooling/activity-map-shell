# Antora component normalization

Activity Map Shell now participates in the Desktop Tooling docs hub as a continuously published Antora component. Its component root supplies the landing-page link, so the redundant `Activity Map Shell > Activity Map Shell` navigation item was removed.

The landing page now carries reader and author metadata, describes the current single companion window accurately, and uses valid punctuation instead of mojibake. The public README links directly to the component on the Desktop Tooling docs hub.
